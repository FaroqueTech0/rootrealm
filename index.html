ROOTREALM

Advanced Android system tools for root, Shizuku, ADB, backup, debloating, battery diagnostics, memory information, and device management.

Download Latest APK

Features

  • 🔓 Root access management — detect and use root access for supported privileged operations
  • 📱 Shizuku integration — access supported privileged operations through Shizuku
  • 🖥️ ADB tools — run supported shell commands and manage device settings
  • 💾 Backup & restore — back up and restore supported apps and data, subject to Android restrictions
  • ✉️ SMS & call-log backup — optional backup features that use the relevant permissions
  • 🧹 Debloating — disable or remove supported system apps where permissions allow
  • 🔋 Battery Manager — inspect charging status, voltage, current, power, and compatible charging controls
  • ⚡ Requestable Wattage — show compatible wired or wireless charging options when the device and kernel support them
  • 🧠 Memory information — view physical and usable RAM, ZRAM, disk swap, and RAM Expansion separately where available
  • ⚙️ Device management — view system information and manage supported device-level settings

Requirements

  • Android 12 (API 31) or higher, subject to the minimum SDK of the published build
  • Root access or Shizuku for features that require privileged operations
  • USB debugging for applicable ADB features
  • Compatible device and kernel interfaces for advanced charging controls
