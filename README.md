## 🧭 About

RootRealm is an Android toolbox by **Faroque Tech** that brings supported root-aware utilities, Shizuku workflows, ADB tools, backups, debloating, and device information into one place.

Some operations require elevated privileges or device-specific support. Review each operation before making system changes.

## ✨ Features

| Icon | Feature | What it does |
|---|---|---|
| 🔓 | **Root access** | Detects root access and uses it for supported privileged operations. |
| 📱 | **Shizuku integration** | Provides supported privileged workflows through Shizuku. |
| 🖥️ | **ADB tools** | Runs supported shell commands and manages compatible device settings. |
| 💾 | **Backup & restore** | Handles supported app, data, and device backup workflows subject to Android restrictions. |
| ✉️ | **SMS & call-log backup** | Offers optional backup functions using relevant permissions. Restoration depends on Android version and default-app requirements. |
| 🧹 | **Debloater** | Disables or removes supported packages where access and Android restrictions allow. |
| 🔋 | **Battery information** | Inspects charging status, voltage, current, and power; available controls depend on hardware and kernel support. |
| 🧠 | **Memory information** | Displays available system memory information, including RAM and swap details where exposed by the device. |
| ⚙️ | **Device management** | Provides system information and supported device-level tools. |

> Feature availability varies by device, Android version, ROM, kernel, permissions, and access method.

## 📋 Requirements

- 📱 An Android device. RootRealm's documented target is Android 12 (API 31) or higher; check the installed build's actual minimum SDK.
- 🔑 Root access or Shizuku for features that need privileged operations.
- 🔌 USB debugging for applicable ADB workflows.
- 🧩 Compatible hardware, kernel interfaces, and permissions for device-specific controls.

Not every feature is available on every device.

## 🔐 APK Authenticity & Safety

The official RootRealm repository is the primary source for releases, APKs, and release notes.

### Before installing an APK from another source

1. Compare the APK's **SHA-256 checksum** with a checksum published by Faroque Tech for the same release, when available.
2. Compare its signing-certificate fingerprint with the official release certificate, when that reference is available.
3. Check the package name, version name, and version code against official release information.
4. Prefer the official release page for future updates.

A matching SHA-256 checksum establishes that two files are identical to each other. A matching signing certificate can help confirm that the same signing key was used. Neither check guarantees that software is vulnerability-free.

**⚠️ A file is not automatically official because it uses the RootRealm name, icon, package name, or screenshots.** Unverified third-party copies may be outdated or modified.

### 🐛 Report a suspicious copy

[Report it through GitHub Issues](https://github.com/FaroqueTech0/rootrealm/issues). Include the download URL and version details, and avoid sharing private information or sensitive device data.
